# Roostack Help

Roostack runs useful services on a computer you own: your photos, your
passwords, your own git server, and more. It installs them with a click,
gives each one a secure web address, backs them up every night and keeps
them up to date. You manage it all from a web page.

This help explains how to use it. It's written for the person looking after
Roostack, who doesn't need to know how computers work inside. Where there's
more to know for technical people, it's one click away, under **For
technical users**.
