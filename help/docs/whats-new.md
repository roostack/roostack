# What's new

What each **series** of Roostack releases brings. A series is a minor
version, such as 0.5: its first release (0.5.0) brings the changes below,
and the releases after it (0.5.1, 0.5.2) only fix things. Each server
installs those fixes by itself; a new series waits until you say yes, on
**Settings → Updates and restarts** (see
[Roostack's own updates](settings/updates.md#roostacks-own-updates)).

When a new series is out, that page links here, to its section. Read it
before you update: a new series can change how things work.
