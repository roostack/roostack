# Roostack brand

Roostack's marks, wordmarks and icons. Decided 2026-10-01 (SPEC.md §3.2, "Brand mark and wordmark"). Every file here is generated by [generate.py](generate.py): change the script, not the files.

## Files

| Files | What | Use |
|---|---|---|
| `perch-*.svg` | **Perch**: a hen on two rack servers with "online" lights | Primary mark |
| `nest-*.svg` | **Nest and egg**: a cracked egg on three woven layers | Alternate mark |
| `perch-cloud-*.svg`, `nest-cloud-*.svg` | The same on a cloud | Roostack Cloud |
| `small-cloud-*.svg`, `favicon-cloud.*`, `apple-touch-icon-cloud.png`, `brandmark-cloud.svg` | **Roostack Cloud's small mark**: the same hen on a plain cloud in the highlight colour, with one light | Roostack Cloud's website (its tabs, top bar and home-screen icon), copied there by its `tools/sync-design.sh`, so it's told apart from Roostack at a glance |
| `small-*.svg`, `favicon.svg` | **Small mark**: the hen (no wing line) on one plain server | Anywhere under about 32px: browser tabs, the app's top bar, the help site's logo. `favicon.svg` switches light/dark with the device setting |
| `wordmark-*.svg` | "roostack" (or "roostack cloud") alone | Where the mark is already nearby, or there's no room for it |
| `lockup-*.svg` | Mark and wordmark side by side | Headers, the website, slides |
| `favicon.ico` | Small mark at 16, 32 and 48px | Browsers and tools that only ask for `/favicon.ico` |
| `apple-touch-icon.png` | Small mark, 180px, square (iOS rounds the corners itself) | iPhone and iPad home screens |
| `icon-512.png` | Small mark, 512px | App stores, social previews, anywhere that wants a bitmap |

Each SVG comes in three versions:

- **`-light`** and **`-dark`**: the mark on a soft-highlight tile, for light and dark backgrounds.
- **`-mono`**: one colour, no tile. Every hole (eye, vents, lights, crack, gaps) is transparent, so it works on any background, in print, or engraved. It uses `currentColor` (the light-mode text colour by default), so when inlined in HTML, CSS `color` sets it.

**Copies elsewhere in the repo**, written by the same script:

- `internal/web/brandmark.go`: the small mark for the top bar, coloured by the `bm-*` classes in `app.css` so it follows the user's theme.
- `internal/web/static/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`: linked from every page.
- `help/docs/assets/logo.svg`: the help site's logo and favicon.
- `mailkit/mark.png`, `mailkit/mark-cloud.png`: the small marks (Roostack's and Roostack Cloud's, light, 96px) embedded in emails, which can't show SVG.

## Colours

From the default theme, Teal and violet ([themes/teal.css](../../internal/web/static/css/themes/teal.css)), and the shared status colours ([tokens.css](../../internal/web/static/css/tokens.css)). In Roostack itself the mark uses the same tokens from the user's theme.

| Part | Token | Light | Dark |
|---|---|---|---|
| Tile, and every cut-out (eye, crack, gaps) | `--highlight-soft` | `#ede9fe` | `#2a1e47` |
| Hen, servers, egg, nest, text | `--fg` | `#1b2426` | `#e5eceb` |
| Comb, wattle, cloud, "cloud" in the wordmark | `--highlight` | `#7c3aed` | `#c4b5fd` |
| Online lights | `--ok-on-fg` | `#7ee2ae` | `#17603f` |

The lights sit on the server, which is the opposite of the background (dark servers in light mode, light servers in dark mode), so each mode uses the other mode's status green.

## Geometry

Everything is drawn on a 64-unit grid. On the tile the full marks are scaled to 81.25% with a 6-unit margin; the small mark fills the tile itself. The tile has 14-unit rounded corners.

- **Hen:** one outline with three curved tail feathers, a wing line, a three-lobed comb and a wattle, and toes gripping the top server. The comb, wattle and beak are drawn first and the body covers their bases; the body has a thin outline in the tile colour, which keeps a light comb separate from a light head in dark mode.
- **Servers:** two rack units, each with rack ears and screw holes, a green online light, a dimmer second light and five vents.
- **Egg:** narrower at the top, with a shine mark and a crack with one branch. The crack is in the tile colour, so it reads as a split showing the tile behind.
- **Nest:** three rounded layers with a few evenly spaced weave strokes (5, 4 and 2), changing direction from layer to layer.
- **Clouds:** the same lights and vents as the servers.
- **Small mark:** the hen at 120% without its wing line, on one plain server with one light.

The dim details (second light, vents, weave, shine) are the tile colour at 45–55% opacity; in the mono versions they're full cut-outs.

## Wordmark

Lowercase "roostack" in [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) (SIL Open Font License), converted to outlines so nothing loads a font.

| Version | Type |
|---|---|
| Perch | "roo" medium (500) + "stack" bold (700), letter spacing −0.03em |
| Nest | all medium (500), letter spacing −0.02em |
| Cloud | adds " cloud" in medium, in the highlight colour |

In a lockup, the wordmark's type is half the mark's height, 0.4em after the mark, centred on it.

## Regenerating

```sh
python3 assets/brand/generate.py
```

This rewrites the marks, the small mark and the copies in the app and help site. PNG and ICO files need `rsvg-convert` (`brew install librsvg`, `apt install librsvg2-bin`).

The wordmarks and lockups need the font file and the [fontTools](https://github.com/fonttools/fonttools) package, which aren't part of the repo. Without them, the existing wordmark files are left as they are:

```sh
python3 -m venv /tmp/brand && /tmp/brand/bin/pip install fonttools
curl -LO 'https://github.com/google/fonts/raw/main/ofl/spacegrotesk/SpaceGrotesk%5Bwght%5D.ttf'
/tmp/brand/bin/python assets/brand/generate.py --font 'SpaceGrotesk[wght].ttf'
```

After changing the small mark, regenerate the design gallery (`go test ./internal/web -run TestGalleryFile -update-gallery`) and check it in both modes.
