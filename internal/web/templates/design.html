Design system

Every colour, size and component MyLab's pages use, in light and dark. Pages should only use what's here; if something new is needed, add it to the design system first (docs/DESIGN.md).

Two kinds of component: template components have shared markup and are called with {{"{{"}}template "name" …{{"}}"}} (the markup shows the call and the HTML it renders); HTML and CSS classes are written as plain HTML using the classes shown.
