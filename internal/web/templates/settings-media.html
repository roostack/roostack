Media libraries

Films, TV, music, books and photos you already have, on drives and in folders, for services like Plex, Jellyfin and Navidrome to play. Services can read them but never change them, and Roostack doesn't back them up: they're things you have elsewhere or keep safe yourself.

Where they are
On the server
Each library is mounted read-only at /mnt/roostack-library/<name>. Roostack never writes there.
In a service
The libraries chosen for it, read-only, each in a folder of its name inside the folder its package says (often /media). Each service has its own folder of them, /mnt/roostack-library-views/<service>, so a drive plugged in later appears in the running service too.
Drives
Mounted read-only by their filesystem's UUID in /etc/fstab (nofail, x-systemd.automount), like backup drives: one that's unplugged never holds up booting. A library read as its owner is an idmapped mount (X-mount.idmap): the owner's files show as Roostack's, for that library only.
Backups
Not backed up.
