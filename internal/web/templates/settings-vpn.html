Technical details

Interface roostack-people on {{.Way.Server}}, UDP 51822, with addresses in 100.96.128.0/17, one for each device. Its settings are in /etc/wireguard/roostack-people.conf, and the firewall's rules for each device are in Roostack's table (nft list table inet roostack). Caddy lets each device through to the services its person may use, and to Roostack's pages only if they're ticked for it. Roostack keeps only each device's public key.
