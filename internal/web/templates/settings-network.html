DNS for your devices

A DNS server finds the address of each name a device looks up, and one such as Pi-hole can leave out ads and trackers while it does. The lab's VPN devices will use the one chosen here wherever they are, and so will the servers you tick. For the other devices at home, set it in your router as the DNS server it gives out.

{{with $.ResolverServers}}
Servers that use it too {{range .}}{{end}}

Only worth it for a server whose own lookups should leave out ads too. It will ask this DNS server first, and keep its own for when it doesn't answer. It will also trust it for every name it looks up, including the time servers it sets its clock from, so tick a server only if you trust this DNS server as much as the server itself.

{{end}}

A device's file names the DNS server only if the device can reach it, so download it again to pick up a change. (Technical: a DNS = line in its WireGuard file, and a systemd-resolved drop-in, /etc/systemd/resolved.conf.d/roostack.conf, on each server you tick.)
