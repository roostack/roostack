Adding a server outside your home (port forwarding)

A server elsewhere connects to this one through your home router, which only lets it in if you ask it to. Roostack already allows it through this server's own firewall; the router is the step it can't do for you.

  1. Open your router's settings page (often http://192.168.1.1 or http://192.168.0.1; the address and password are usually on a sticker on the router).
  2. Find Port forwarding. Some routers call it Virtual server, NAT, Port mapping or put it under Advanced or Firewall.
  3. Add a rule: protocol UDP (not TCP), port 51820, to this server{{with .LANAddr}} at {{.}}{{end}}, port 51820.
  4. Use your home's public address above, e.g. 203.0.113.7:51820. Search "what is my IP" from a device at home to find it. If it changes now and then, a name from your domain that points home works better.

How to tell it worked: once the new server has joined, it shows up above as up to date. If joining says it can't reach the controller, the port isn't forwarded yet (or the address is wrong). Some internet connections (called CGNAT) can't forward ports at all; then put the controller on the server that's reachable instead.
