Checklist

  1. Protection. {{if .Protected}}CrowdSec is running: it blocks addresses that attack your services, and password tries are limited. {{else}}CrowdSec is starting (its first start downloads it, which takes a few minutes).{{if not .Internet}} The address's DNS record waits for it.{{end}}{{end}}
  2. {{with .Record}}{{end}}DNS record. {{with .Record}}{{.Message}}{{else}}Roostack is checking it.{{end}}
    3. {{if .Internet}}
  3. Your provider's firewall. Many cloud providers put a firewall in front of your server, such as Linode's Cloud Firewall, Hetzner's Firewall, AWS security groups, DigitalOcean's Cloud Firewalls or Oracle Cloud's security lists. In your provider's control panel, allow TCP ports 80 and 443, and UDP port 443, from anywhere. No provider firewall? There's nothing to do here.
    4. {{else}}
  4. Your router. Forward TCP ports 80 and 443, and UDP port 443, to {{or .LANIP "this server"}}{{with .LANIP}} (this server){{end}}. Look for "port forwarding", "virtual server" or "NAT" in your router's settings. Port 443 already goes to another device at home? It has to come here instead, or wait for public access through a cloud server. If this server is a cloud server, say so in Settings → Where it is and DNS.
    5. {{end}}

If the check link doesn't open

Look at these in order: whatever is in the way is usually the first one that's wrong.

  1. Roostack's own firewall lets web traffic in (TCP 80 and 443, UDP 443). It always does.
  2. {{if .Internet}}Your provider's firewall allows those ports (above). Roostack can't see it from here. {{else}}Your router forwards those ports to this server (above). Roostack can't see it from here.{{end}}
  3. Public DNS points {{.Route.Host}} at {{with .Record}}{{.IP}}{{else}}this lab{{end}}: {{if and .Record (eq .Record.State "ok")}}it does (Roostack checked).{{else}}not yet, see the DNS record step.{{end}}
    4. {{if not .Internet}}
  4. Your internet connection can take incoming connections at all: some (called CGNAT, common on mobile and some fibre plans) can't. Tell me more{{template "new-window"}}
    5. {{end}}
