When the service registry warns of a security problem

The service registry's maintainers publish a warning when a problem affects a service in the registry, naming the versions affected and the version that fixes it. Roostack is checking for them every hour.

Critical means anyone on the internet could use it without signing in. Services you added yourself are never paused by Roostack: if they might be affected, Roostack will tell you.
