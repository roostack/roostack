Settings

Updates

Updates will be shown on its page and under “Needs attention”, and you'll apply them.

Fix releases will go on automatically after the nightly backup, and larger updates will be shown for you to apply.

Fix and feature releases will go on automatically after the nightly backup; not new major versions, which can change how it works.

Every update will go on automatically after the nightly backup, new major versions too.

When automatic updates wait

Automatic updates need backups set up and wait for you when an update has notes to read. If the service registry says the version Forgejo runs is dangerous and Roostack stops it, a fix it would take automatically will be applied straight away.

Saving will restart Forgejo when its address, settings, or libraries change, and it will be unavailable for a moment.

Name

This will change what it's called on your pages. Its name, forgejo, is used for its folders, containers, and backups, so it will stay.

Environment variables

Advanced

Forgejo reads many of its options from environment variables. Ones you add here will go to Forgejo just as you type them, and Roostack will keep them through updates. Forgejo's list of options

Roostack can't check them: a wrong value can stop Forgejo starting, and if it does, removing the variable here will start it as it was. Saving a change will restart Forgejo, and it will be unavailable for a moment.

Variables Forgejo's package sets

Roostack sets these from Forgejo's settings, its database, its address, and single sign-on, so they can't be added here: change them through the settings above.

FORGEJO__database__DB_TYPE FORGEJO__database__HOST FORGEJO__database__PASSWD FORGEJO__server__ROOT_URL FORGEJO__server__DOMAIN FORGEJO__service__DISABLE_REGISTRATION FORGEJO__security__SECRET_KEY USER_UID USER_GID

Technical details

They're kept in Forgejo's instance file (/var/lib/roostack/services/forgejo.yaml), so backups and moving Forgejo to another server keep them; a secret's value is a Podman secret, roostack-forgejo-env-<name>, given to the container as that variable. Forgejo's container file on its technical side shows them after the package's own (Environment=, and Secret= for a secret). Up to 100 per service, each value up to 4 KB.
