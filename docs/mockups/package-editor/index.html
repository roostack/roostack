Your Compose file

Paste it, or open a file. Only this file is read: an env_file or .env isn't, so paste what's in it below the file if you want its values.

services:
  vikunja:
    image: vikunja/vikunja:0.24.6
    environment:
      VIKUNJA_SERVICE_PUBLICURL: http://localhost:3456
      VIKUNJA_DATABASE_HOST: db
      VIKUNJA_DATABASE_PASSWORD: changeme
      VIKUNJA_DATABASE_TYPE: postgres
      VIKUNJA_DATABASE_USER: vikunja
      VIKUNJA_DATABASE_DATABASE: vikunja
      VIKUNJA_SERVICE_JWTSECRET: ${JWT_SECRET}
    ports:
      - 3456:3456
    volumes:
      - ./files:/app/vikunja/files
      - /var/run/docker.sock:/var/run/docker.sock
    depends_on:
      db:
        condition: service_healthy
    restart: unless-stopped
  db:
    image: postgres:17
    environment:
      POSTGRES_PASSWORD: changeme
      POSTGRES_USER: vikunja
    volumes:
      - ./db:/var/lib/postgresql/data
    restart: unless-stopped
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U $$POSTGRES_USER"]

What came across

Two services: vikunja became the container vikunja, and db a Postgres database Roostack runs for it and backs up.

9 Converted

  • The image vikunja/vikunja:0.24.6, as docker.io/vikunja/vikunja:0.24.6; the version 0.24.6-roostack.1 from its tag.
  • Port 3456 as the web address web, at vikunja.your lab.
  • VIKUNJA_SERVICE_PUBLICURL as the service's own address, {{ .Routes.web.URL }}.
  • VIKUNJA_DATABASE_HOST, _USER and _DATABASE as the database's details; _PASSWORD as the password Roostack makes for it.
  • ${JWT_SECRET} as a secret Roostack generates, jwt_secret.
  • ./files as the storage files, backed up.
  • depends_on: db, as starting after the database.

1 Not allowed

  • /var/run/docker.sock: it would give the app control of every container on the server. Roostack never mounts it; if the app needs it for something, that part won't work.

5 Not needed in Roostack

  • restart (both): Roostack restarts services that stop.
  • db's volume, environment and health check: Roostack keeps Postgres's data, makes its user and password, and checks it itself.
  • condition: service_healthy: Roostack waits for the database anyway.

6 Over to you

  • Pin the image by its digest (the editor can't look it up offline): skopeo inspect --raw docker://docker.io/vikunja/vikunja:0.24.6 | sha256sum
  • Say how much memory each container uses, what the storage holds, and where people sign in.
  • The facts about the project: who makes it, its licence and logo.

Name and version

The project 3

The app's licence, as an SPDX identifier. Take it from the project's own licence file or notice.

AGPL-3.0 doesn't say whether later versions apply. Read the project's notice: "or (at your option) any later version" means or later.

Closed source, with only an image to run? Use closed, and give the website instead. Package format: about

From the source address: releases at https://kolaente.dev/vikunja/vikunja/releases/tag/v{version}?
