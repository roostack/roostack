Sam's tablet is ready to add

  1. Install a WireGuard app on the device. WireGuard's own is free for iPhone and iPad, Android, Windows, macOS, and Linux.
  2. In the app, add a tunnel from a QR code and scan this one. On a laptop, add it from a file instead: download sams-tablet.conf.
  3. Turn the tunnel on. The list of devices will show when it last connected.

You'll only see this once. The settings hold the device's private key, which Roostack doesn't keep, so if you lose them, add the device again.
