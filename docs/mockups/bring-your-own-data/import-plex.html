Media it read

Media stays where it is, as media libraries: Plex reads it, and nothing is copied. Each library is shown inside Plex where the old folder was, so Plex finds every film where it expects it, with what everyone has watched.

/movies and /tv aren't in one folder, so each library is shown at its own place. If the Films drive is unplugged, Plex can't see it again until it restarts: Roostack restarts Plex by itself once the drive is back, which takes a few seconds.

Plex's media folder goes at /data, with Films in it as movies and TV as tv, the names they had. A drive unplugged and plugged back in comes back by itself.

On the old machine

Roostack never runs anything there. What you do:

  1. Copy its config folder here, or onto a drive. Cache, Codecs, Crash Reports, Logs and Updates can be left out.
  2. Plex has no database to dump: its database is a file in that folder. Stop Plex before the last copy.
  3. Keep it stopped once you switch: two servers with one identity fight over it on plex.tv.
