Technical details

Roostack reads these every minute from /proc (processors, memory, swap, load, and network), /sys/class/hwmon (temperatures), and each service's systemd unit's cgroup under the roostack user's manager (its memory and processor time), with no extra software. The controller keeps every reading for two days, then hourly averages and peaks for as long as History's setting.

Roostack will tell you, here, under Needs attention, and by email (Problems), when less than 10% of the memory has been free for 15 minutes, when the server is swapping heavily for 15 minutes, or when a temperature reaches its sensor's own high mark.
