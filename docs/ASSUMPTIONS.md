# Working Assumptions & Concerns

Code was started before the Debian 13 rootless prototype (TASKS 1.2) was run. This file lists what the code **assumes** that prototype will show so that each item can be checked on a real VM and the code adjusted.

Status: items are **unverified** unless marked. ✅ = verified on the Debian 13 dev VM (`scripts/dev-vm.sh`, Podman 5.4.2, 2026-09-26). ❌ = failed. ⚠️ = could force a redesign if wrong.

## D. TLS / Caddy

| # | Assumption |
|---|---|

| D2 | DNS-01: seven providers from the `internal/dns` registry (fields, Caddy directive, libdns client), plus a raw override directive for anything else. | D3 | **The DNS challenge is checked with public resolvers (2026-10-14).** Caddy waits to see a challenge's TXT record before asking Let's Encrypt, asking the domain's own name servers, which it finds through a resolver. Caddy tries them in turn. **Seen so far:** the router came unstuck by itself after about four hours (Porkbun still answering), and Caddy then got the certificate (a real one, YE1; its retries had used Let's Encrypt's staging). Caddy accepts the `resolvers` line (VM3). **Not verified:** a certificate obtained through it while a resolver is stuck. |
