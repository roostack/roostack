Every colour, size and component MyLab's pages use, in light and dark. Pages should only use what's here; if something new is needed, add it to the design system first (docs/DESIGN.md).

This file is generated from the same templates as the /design page in MyLab (go test ./internal/web -run TestGalleryFile -update-gallery). Don't edit it by hand.

Buttons

One primary button per form or card; others secondary or quiet.

Primary, secondary, danger, quiet

Primary does the main thing. Danger removes or deletes. Quiet is for small or optional actions.

Markup
<div class="actions-row"><button>Back up now</button><button class="secondary">Cancel</button><button class="danger">Remove</button><button class="quiet">Set this up later</button></div>
