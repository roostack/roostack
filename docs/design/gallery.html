Design system

Every colour, size, and component Roostack's pages use, in light and dark. Pages should only use what's here; if something new is needed, add it to the design system first (docs/DESIGN.md).

Two kinds of component: template components have shared markup and are called as functions, e.g. {{notice "warn" "…"}} (the markup shows the call and the HTML it renders); HTML and CSS classes are written as plain HTML using the classes shown.

This file is generated from the same templates as the /design page in Roostack (go test ./internal/web -run TestGalleryFile -update-gallery). Don't edit it by hand.

Layout

Console glass (2026-10-14): a sidebar floating beside the page, the page's header on the page, cards on a faint moving aurora (it stops for reduced motion). The layout (templates/layout.html) draws all of it; a page gives its title, content and, if it wants, its breadcrumbs and help. Below 900px the sidebar is a drawer behind the menu button.

Sidebar Template component

The lab's name, the main areas (Settings last, for those who can change settings), then Help, Light/Dark/Auto and the person. A main area's own pages hang under it while you're there (.nav-children of .nav-sub, each with a 16 px icon): under Services each service (its logo, .nav-logo, or its drawn icon) and Add a service; under Settings every settings page (settingsArea.Icon). Beside Servers, how many need attention (.nav-count, a warning pill). Where you are has aria-current="page" (its main area "true"): the highlight tint with a faint highlight edge. The surface at 70% with a blur: status shows here only as a pill on its own tint, never as bare text (the contrast test checks text, muted text and links on it).
